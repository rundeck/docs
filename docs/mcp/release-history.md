# MCP Server Release History

This page gives a high-level summary of each Rundeck MCP Server release. For the complete list of changes in every version, including dependency updates and contributor credits, see the full [CHANGELOG](https://github.com/rundeck/mcp/blob/main/CHANGELOG.md) on GitHub.

## 1.1.0

Released October 28, 2026.

A maintenance release with dependency updates, packaging improvements, and other fixes.

- Updated core dependencies, including the Model Context Protocol SDK packages.
- The Docker image now reports its release version in its User-Agent.
- Added an Apache-2.0 license file to the project.

[Full release notes](https://github.com/rundeck/mcp/releases/tag/v1.1.0)

## 1.0.0

Released August 26, 2026.

The first full public release of the Rundeck MCP Server.
