## Support Status

- **Supported**: The current release series. It receives active maintenance, including bug fixes, security updates, and compatibility improvements.
- **Maintenance Support**: When a new major version is released, the previous series moves to Maintenance Support. Versions in this state continue to receive critical security fixes, but bug fixes are rare and are generally reserved for high-severity issues. To receive ongoing fixes and new capabilities, upgrade to the current supported release series.

## Requirements Are Version-Specific

::: warning
System requirements and usage details — including supported operating systems, Java runtime, and databases — can change between major versions. The requirements published on this site reflect the current release (**{{ $rundeckVersion }}+**).

If you run an earlier self-hosted series, the requirements for your version may differ. Select your version from the version menu to view the requirements and usage details that apply to it. For example, **Amazon Linux 2023** is supported on **6.0+** but is not supported on the **5.x** series.
:::
